# 时间安排

大熊猫基地适合安排在上午。早间既是活动较活跃的时段，也是入园与热门展区排队的高峰，应为入园、步行和排队预留缓冲，不要把上午排得没有余地。

# 跨区交通

基地与市中心存在明显距离，跨区移动需要预留显著长于市区内景点的交通时间；不要把基地与市中心多个景点硬塞进同一个半天。具体车程、拥堵和接驳方式必须以实时路线数据为准。

# 事实边界

开放时间、门票、预约和园区接驳信息属于实时事实，必须以官方渠道或实时 provider 为准，知识库只能提供安排原则。
