# 远郊安排

兵马俑位于西安中心城区之外，往返交通、安检和排队会占用大量时间。当天其余景点应尽量与临潼方向一致，或减少数量；不要把兵马俑与市中心多个景点紧密串联。

# 时间缓冲

应预留往返车程、入园排队和景区内步行的缓冲。若同行有老人儿童、天气炎热或行程起点较晚，应进一步减少当天景点数量，而不是压缩交通时间。

# 事实边界

开放时间、门票预约、讲解服务和交通接驳属于实时事实，必须以官方渠道或实时 provider 为准。
