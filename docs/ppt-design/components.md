# 图形母题与组件

> 知识库版本 1.0 · 2026-10-23
> 原则：母题承担叙事功能，不做纯装饰；全部使用原生形状，保证可编辑。

## 1. 基本母题（从参考稿提炼）

| 母题 | 含义 | 用法 |
|---|---|---|
| **满版色块** | 章节 / 停顿 | 封面、章节页、结尾；**全片 ≤ 4 页** |
| **双色分屏** | 对比 | 真实 vs 估算、调整前 vs 调整后 |
| **圆角编号卡** | 流程步骤 | Plan / Verify / Replan / Explain 四步，编号用等宽字 |
| **珊瑚尖角** | 章节标记 | 24px 珊瑚尖角 + 2px 短线，全篇统一，不做箭头变体 |
| **大号衬线数字** | 关键指标 | 96pt 衬线数字 + 12pt 灰色说明 |
| **细线网格** | 可校验 | 证据页用 48px 浅网格 + 珊瑚路径，透明度 6% |

## 2. 自创母题（本套 deck 专有）

| 母题 | 规格 | 含义 |
|---|---|---|
| **注册角标** | 截图四角 8px 珊瑚短角线 | “这是证据原件”的印刷对位感 |
| **状态胶囊** | 12px 圆角、1px 描边、12pt 等宽字 | `REAL` / `ESTIMATED` / `CURATED` / `UNAVAILABLE` 四种状态 |

状态胶囊配色：

| 状态 | 底 | 字 |
|---|---|---|
| REAL | 纸白 `#FAF9F5` | 墨 `#1F1F1F` |
| ESTIMATED | 珊瑚浅 `#FBF0EA` | 珊瑚深 `#8F3F26` |
| CURATED | 米色 `#EEDDCC` | 墨 `#1F1F1F` |
| UNAVAILABLE | 中性灰 `#C9C6BF` | 次文 `#6B6660` |

## 3. 使用规则

1. 一页最多两个母题，且必须有一个是主角
2. 同一母题全篇含义固定：尖角 = 章节、分屏 = 对比、网格 = 校验、角标 = 证据
3. 只用现有色板；珊瑚单页面积 ≤ 15%（满版页除外）
4. 全部用原生形状/矢量，不做位图贴图
5. 满版色块页全片不超过 4 页

## 4. 落位

| 页 | 母题组合 |
|---|---|
| 封面 | 满版珊瑚 + 大号衬线标题 + 一组细白线 |
| 第 3 页 闭环 | 圆角编号卡 + 珊瑚尖角连接 |
| 第 5–7 页 Verify / Replan / Explain | 细线网格 + 注册角标 + 状态胶囊 |
| 第 12 页 诚实降级 | 双色分屏（真实 / 估算） |
| 第 13 页 工程数字 | 三个大号衬线数字 |
| 结尾 | 满版珊瑚 + 白色尖角收束 |

## 5. 制作

- 形状类（色块、卡片、尖角、角标）直接用 PowerPoint / WPS 原生形状，坐标按 1920×1080 网格
- 网格背景用重复 1px 线，或 SVG 导出 PNG（透明度 6%）
- 胶囊与角标做成母版组件，复制使用，保证一致
