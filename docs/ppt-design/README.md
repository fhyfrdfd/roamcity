# PPT 设计知识库

> 本目录是 Voyage 对外演示文稿的**唯一视觉依据**。做 PPT 前先读这里，不要在单页里临时发明样式。

## 文件

| 文件 | 内容 |
|---|---|
| `palette.json` | 机器可读 token：颜色、字号、网格、圆角、阴影 |
| `style-guide.md` | 设计规范：配色、字体、网格、页面原型、截图与图表处理、禁忌 |
| `typography.md` | 字体栈、字号层级、安装与回退策略 |
| `components.md` | 图形母题与组件（色块、分屏、编号卡、角标、状态胶囊） |
| `schemes.md` | 三套方案 + 备选方向 + 15 页定稿映射 |
| `references.md` | 12 张参考图的逐页清单与可复用结论 |

## 来源

- 风格参考：`shots/微信图片_20261023162313_322_2.jpg` … `_333_2.jpg`（12 张）
- 内容识别：**Anthropic Research Overview** 风格的英文 deck，共 12 页
- 画布：截图 1440×3120，含查看器黑边；真实页面约 1210×1685，**竖版约 5:7**
- 取色方法：浏览器 canvas 在幻灯片区域（y 25%–70%）按色簇求均值；程序结果与逐页读图交叉验证一致
- 实测占比：暖白 `#FAF9F5` 49.5%、珊瑚 `#D97757` 14.4%、近黑 `#0F0E0E` 10.6%、雾蓝 `#6699CC` 8.5%、薄荷 `#BBDDCC` 6.5%、薰衣草 `#CCCCDD` 5.8%、米色 `#EEDDCC` 4.7%

## 两个关键约束

1. **参考稿是竖版，我们是 16:9**：只借色彩、字体、元素语言，版式按 `style-guide.md` 第 5 节重新排布。
2. **大色块用直角，卡片和截图用圆角**，两者不混用；阴影只给截图。

## 三条容易被忽略的硬规则

- 有截图的页面，底色必须是纯白 `#FFFFFF`（暖白会衬出截图边界）
- 标题字号 ≥ 正文 × 2.2，行高 1.35
- 深红色 `#990022` 面积 < 3%，只做角标

## 使用方式

1. 选方案：默认 `schemes.md` 方案 A（A+C 混合做节奏），品牌统一优先时用方案 B
2. 取 token：颜色/字号/网格一律引用 `palette.json`
3. 套原型：`style-guide.md` 第 5 节的 9 种页面原型覆盖全部页面，不新增原型
4. 素材：截图统一 `shots/deck/`，按 `01-workspace.png` 语义命名；与桌面截图同一条旅行数据

## 硬性检查（交付前）

- [ ] 每页颜色 ≤ 3 种，强调色只出现一次
- [ ] 没有纯黑 `#000000`、没有渐变、没有艺术字
- [ ] 正文 ≥ 18pt，注释 ≥ 12pt，中文每行 ≤ 32 字
- [ ] 截图圆角 12px、1px `#E4DDD2` 描边、未拉伸
- [ ] 每页留白 ≥ 35%

## 维护

重新提取配色时，用 Playwright 在幻灯片区域按色簇采样；更新 `palette.json` 的 `version` 与 `updated`，并在 `style-guide.md` 记录变更原因。参考图变更时先更新本文件的「来源」与 `references.md`，再改 token。
