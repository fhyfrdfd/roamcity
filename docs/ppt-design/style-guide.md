# Voyage 演示文稿 · 风格指南

> 知识库版本 2.0 · 2026-10-23
> 依据：`shots/` 下 12 张参考图（编号 322–333），经逐页读图确认为 **Anthropic Research Overview** 风格的英文竖版 deck

## 1. 风格定位

**编辑型科技报告**：暖白底、珊瑚橙强调、低饱和 pastel 分区、大字标题、大量留白。像一份排版讲究的研究报告，而不是商务模板。

来源说明（重要）：

- 参考稿是**竖版**页面（约 5:7，内容区约 1210×1685），截图上下是查看器黑边，不是设计
- 我们的演示稿是 **16:9**：只借用**色彩、字体、元素语言**，版式必须重新排布，不要照搬
- 参考稿共 12 页，页型包括：封面拼贴、目录、章节页、双卡页、长文页、大字页、数据页、时间线、致谢页

## 2. 色彩

| Token | 色值 | 实测占比 | 用途 |
|---|---|---:|---|
| `canvas` | `#FAF9F5` | 49.5% | 页面底色 |
| `surface` | `#FFFFFF` | — | 截图衬底、需要更干净的区域 |
| `ink` | `#0F0E0E` | 10.6% | 标题与正文；深色页背景 |
| `coral` | `#D97757` | 14.4% | 主强调：封面、目录、章节页、关键数字 |
| `mist_blue` | `#6699CC` | 8.5% | 次强调：对比数据、时间轴、分区块 |
| `mint` | `#BBDDCC` | 6.5% | 大字页底、正向数据块 |
| `lavender` | `#CCCCDD` | 5.8% | 并列卡片底 |
| `beige` | `#EEDDCC` | 4.7% | 引用块、说明区 |
| `deep_red` | `#990022` | <1% | 仅图标/角标点缀 |
| `line` | `#E4DDD2` | — | 1px 分隔线、表格线 |

硬规则：

- 每页最多 **3 个颜色**（底色 + 1 强调 + 1 中性）
- 强调色每页只出现一次；需要“更强”时加深色块面积，不加第二种颜色
- 文字只用 `ink` / `canvas`；彩色文字禁止
- 大色块用**直角**，卡片和截图用圆角，两者不混用

### 珊瑚色阶与对比度

| 阶 | 色值 | 用途 |
|---|---|---|
| 50 | `#FBF0EA` | 卡片底（8% 强度） |
| 100 | `#F3D9CD` | 浅色强调块 |
| 200 | `#E8B29D` | 图表次强调 |
| 500 | `#D97757` | 主强调（标题关键词、关键数字、页码） |
| 600 | `#B85C3E` | 悬停 / 次级强调 |
| 800 | `#8F3F26` | 深色强调，慎用 |

- 珊瑚对白底的对比度约 **3.0:1**：只能用于 **≥24px 的大字**或**珊瑚色块上的白字**
- 正文一律 `#1F1F1F`，禁止用珊瑚色排正文
- 全片配比目标：暖白 75% / 墨色文字 15% / 珊瑚 8% / 深红 2%

## 3. 字体

字体栈、字号、字距与安装方式见 **`typography.md`**，这里只列摘要：

- 标题：Source Serif 4 Semibold → 思源宋体 Bold → 宋体 Bold
- 正文：Inter → 思源黑体 → 微软雅黑
- 标签/页码：JetBrains Mono → Consolas
- 字号：封面 88pt / 章节 64pt / 页标题 40pt / 导语 24pt / 正文 20pt / 图注 13pt / 眉标 12pt
- 行高：标题 1.15，正文 1.6；标题字距 -1%，眉标 +8%
- 标题与正文对比 ≥ 2.2 倍；中文标题左对齐，每行 ≤ 32 字

## 4. 网格与留白

- 画布 1920×1080，页边距 80px，12 栏，栏距 24px，基线 8px
- 标题区高 160px，默认左对齐；封面、章节页、大字页可居中
- 每页留白 ≥ 35%；宁可少一行，不缩字号

## 5. 页面原型（参考稿 → 16:9 翻译）

| 原型 | 参考稿做法 | 16:9 做法 |
|---|---|---|
| `cover` 封面 | 珊瑚 + 白 + 雾蓝 + 薰衣草多色块拼贴，标题压在大色块上 | 左侧 5 栏珊瑚块放标题，右侧 7 栏放产品截图；或珊瑚满版 + 居中标语 |
| `toc` 目录 | 珊瑚满版 + 白色大字列表 | 左 4 栏珊瑚块，右 8 栏三行目录条目 + 页码 |
| `section` 章节 | 珊瑚满版 / 薄荷满版 + 大字 | 整版色块 + 40pt 白字 + 右下角编号 |
| `dual-card` 双卡 | 两块 pastel 各占约一半，标题 + 短段 | 左右两栏，各一张浅色卡片（薰衣草 / 薄荷） |
| `split` 双色分屏 | 雾蓝 46% + 薰衣草 45%，中间细线 | 左右各半；一侧标题、一侧要点，用于目录或对比 |
| `archive` 档案页 | 象牙白底 + 0.5px 细线 + 珊瑚批注 + 等宽编号 | Verify / Explain：象牙白 `#F5F1E8` 底，右侧证据卡，像研究报告 |
| `long-text` 长文 | 94% 白底，靠字号与行宽控制节奏 | 只用一栏文字（≤ 8 栏宽），另一侧留白或小图 |
| `big-type` 大字 | 薄荷底占 47%，同一句话重复两行 | 整版薄荷 + 40pt 黑字两行，不加其他元素 |
| `data` 数据 | 白底折线/柱图，大数字 99.9%、4.5x | 左 3 个珊瑚大数字，右侧一张图；去掉图例 |
| `timeline` 时间线 | 92% 白底，四阶段里程碑 | 横向四段，用 1px 线与珊瑚节点，不用箭头 |
| `thank-you` 致谢 | 珊瑚满版 + 深色大字 “Thank You” | 珊瑚或近黑满版 + 一句使命 + 二维码 |

节奏规则：

- 满版珊瑚页每 4–5 页一次，**不许连续三页出现满版橙**
- 章节过渡也可以只用「珊瑚细条 + 页码」，不必整页铺色
- 内容页里珊瑚只出现在：标题关键词、编号、页码、关键数字

## 6. 截图与图表

- 截图统一圆角 12px、1px `line` 描边、阴影 `0 8px 24px rgba(15,14,14,0.06)`，放在 `surface` 白底上
- **有截图的页面，底色必须是纯白 `#FFFFFF`**；暖白底会衬出截图边界
- 强调截图某处：珊瑚 2px 描边 + 编号角标，不用大箭头
- 图表最多两色：`coral` + `ink`（或 `mist_blue`）；网格线 `line`；数据标签直接标在图形上
- 单强调方案下的图表：主序列珊瑚 `#D97757`，对比序列中性灰 `#C9C6BF`，网格 `#E5E2DC`，不再引入第二种强调色
- 浅色卡片：底 `#FBF0EA`，12px 圆角，1px `#E5E2DC` 描边，**不加阴影**

## 7. 禁忌

- 不用渐变、阴影字、艺术字、3D 立体字
- 不用纯黑 `#000000`；深色统一 `#0F0E0E`
- 一页不超过 3 种字体、不超过 3 个颜色
- 不把竖版参考稿的版式硬塞进 16:9（会导致大面积空白或文字过小）
- 截图不拉伸、不叠半透明色块

## 8. 与 Voyage 产品设计系统的关系

产品 Web 端主色是青 `#0F766E`。两种处理：

- **忠实参考稿**：珊瑚 `#D97757` 为主，青只存在于截图里（推荐）
- **忠于产品**：青为主，珊瑚降为强调（见 `schemes.md` 方案 B）

两案共用暖白底与近黑文字，截图可直接复用。
