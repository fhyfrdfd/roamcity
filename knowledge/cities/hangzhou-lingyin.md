# 台阶与爬坡

灵隐寺和北高峰一带存在台阶、坡道和连续攀爬路段。老人、无障碍需求或低步行耐受用户应减少爬升安排，优先选择平缓区域；现场代步或索道信息以官方为准。

# 与西湖串联

灵隐与西湖之间需要交通衔接，排队和人流会放慢行程。与西湖安排在同一天时，应减少其他景点数量，并在两段之间预留缓冲。

# 事实边界

开放时间、香花券、索道运营和临时管控属于实时事实，必须以官方渠道或实时 provider 为准。
