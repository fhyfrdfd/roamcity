# 三套演示文稿设计方案

> 同一套暖白 + 近黑的底子，三种主色策略。共用 `palette.json` 的字体、网格与截图规则。
> 参考稿是竖版（5:7），以下版式均已按 16:9 重新排布。

---

## 方案 A · 珊瑚编辑部（参考稿还原）

**一句话**：珊瑚负责情绪，暖白负责呼吸，黑色负责落点。

| 角色 | 颜色 |
|---|---|
| 底 | `#FAF9F5` |
| 主强调 | 珊瑚 `#D97757`（封面、目录、章节页、关键数字） |
| 次强调 | 雾蓝 `#6699CC`（对比数据、时间轴） |
| 浅色块 | 薄荷 `#BBDDCC` / 薰衣草 `#CCCCDD` / 米色 `#EEDDCC` |
| 卡片底 | 珊瑚 50 `#FBF0EA`（12px 圆角、1px 描边、无阴影） |
| 文字 | 近黑 `#0F0E0E` |
| 点缀 | 深红 `#990022`（角标、图标，面积 <1%） |

- **封面**：左 5 栏珊瑚块 + 54pt 白字标题，右 7 栏产品截图；或珊瑚满版 + 居中标语
- **目录**：左 4 栏珊瑚块，右 8 栏条目 + 页码
- **章节页**：珊瑚或近黑满版 + 40pt 白字
- **双卡页**：左右各一张薰衣草 / 薄荷色卡片
- **数据页**：珊瑚大数字 + 一行近黑解释；图表珊瑚柱 + 中性灰 `#C9C6BF` 对比柱
- **适合**：想要参考稿那种研究报告气质
- **风险**：珊瑚面积大时投影偏暖，需控制每页占比

---

## 方案 B · 品牌青（与产品界面同源）

**一句话**：PPT 和产品是同一个品牌，青是主色，珊瑚只做点睛。

| 角色 | 颜色 |
|---|---|
| 底 | `#FAF9F5` |
| 主强调 | 青 `#0F766E`（产品主色） |
| 次强调 | 珊瑚 `#C2410C`（仅“变化 / 风险 / 提醒”） |
| 辅助 | 雾蓝 `#6699CC`、薄荷 `#BBDDCC` |
| 文字 | 近黑 `#0F0E0E` |

- **封面**：暖白底 + 左侧青色竖条 + 大字标题；或近黑底 + 青色高亮关键词
- **章节页**：青满版，或暖白底 + 超大青色数字
- **内容页**：暖白底，截图带青 2px 描边强调
- **数据页**：青色数字 + 珊瑚色对比项（“优化前 / 后”）
- **适合**：观众看完 PPT 会立刻打开产品，品牌要连贯
- **风险**：整体偏冷，需要靠米色/珊瑚小面积回温

---

## 方案 C · 夜色珊瑚（高对比，适合投影）

**一句话**：暗场里的珊瑚像地图上的路标，适合大屏与录屏。

| 角色 | 颜色 |
|---|---|
| 底 | 近黑 `#0F0E0E`（次层 `#1B1917`） |
| 主强调 | 珊瑚 `#D97757` |
| 次强调 | 雾蓝 `#6699CC` |
| 文字 | 暖白 `#FAF9F5` |
| 浅色块 | 米色 `#EEDDCC`（小面积） |

- **封面**：近黑满版 + 珊瑚大标题 + 1px 暖白细线
- **章节页**：珊瑚满版（暗场中形成强节奏）
- **内容页**：近黑底 + 暖白文字；截图必须放进白色圆角卡片
- **数据页**：珊瑚大数字 + 暖白注释
- **适合**：大屏投影、录屏、灯光较暗的场地
- **风险**：浅色截图占比高时会显得“黑框包白图”；打印效果差

## 对比与推荐

| 维度 | A 珊瑚编辑部 | B 品牌青 | C 夜色珊瑚 |
|---|---|---|---|
| 与参考稿一致 | ★★★★★ | ★★★ | ★★ |
| 与产品界面一致 | ★★★ | ★★★★★ | ★★★ |
| 浅色截图兼容 | ★★★★★ | ★★★★★ | ★★ |
| 投影对比度 | ★★★ | ★★★★ | ★★★★★ |
| 打印友好 | ★★★★ | ★★★★ | ★ |

**推荐**：主用 **A**，封面与每个章节页切 **C** 的深色版做节奏（A+C 混合）。若评审现场先看了产品演示、希望品牌一致，则改用 **B**。

### 按页面类型的组合配方（推荐直接照此执行）

| 页面 | 用哪套 | 具体做法 |
|---|---|---|
| 内容页 / 长文页 | A | 暖白底，每页至多一个 pastel 色块（≤35%），按章节轮换四色 |
| 封面 / 目录 / 章节页 | A 的满版变体 | 珊瑚满版 + 白字；封面可用多色块拼贴 |
| Verify / Replan 证据页 | C 的冷色变体 | 主色换雾蓝 `#6699CC`（或产品青 `#0F766E`），珊瑚只标风险 |
| 目录 / 对比页 | 双色分屏 `split` | 薄荷\|薰衣草 或 米色\|雾蓝 对分，珊瑚做页码与强调词 |

一句话：**暖白编辑风打底，珊瑚定调，雾蓝承接产品截图。**

## 备选方向（按场合局部启用）

| 方向 | 关键色 | 做法 | 适合 | 风险 |
|---|---|---|---|---|
| **双色桥接** | 珊瑚 `#D97757` + 产品青 `#0F766E` | 珊瑚管观点，青管数据/可信；同页只出现一个强调色，章节交替 | 需要和产品视觉统一 | 两色饱和度接近，必须靠面积拉开，青只用于图表与状态标签 |
| **暗色剧场** | 底 `#141413`、文字 `#F5F1E8`、珊瑚唯一高亮 | 截图做成“发光卡片”浮在深底上：1px 边框 + 8% 珊瑚光晕 | 5–10 分钟路演、投影环境 | 不适合打印；浅色截图连续出现会割裂，需与浅色页交替 |
| **档案纸质感** | 象牙白 `#F5F1E8` + 深墨 `#1F1F1F` + 珊瑚批注 | 0.5px 细线、衬线标题，像研究报告/白皮书 | Verify / Explain 讲证据的页 | 节奏偏平，需要大字页调节 |
| **技术蓝图** | 底 `#F7F7F5` + 1px 网格线、珊瑚关键路径、雾蓝外围标注 | 等宽字体编号（如 `RULE-04`） | 技术评审/内部沟通 | 装饰性强，容易抢内容 |
| **大字海报** | 暖白底 + 珊瑚块 | 每页一句判断句，72–96pt，配一个色块或一张截图 | 5 分钟路演 | 15 页证据型内容撑不住 |

### 按场合选择

| 场合 | 推荐组合 |
|---|---|
| 10 分钟答辩、要讲证据 | 珊瑚单强调打底 + Verify/Explain 两页切档案纸质感 + 封面/结尾满版珊瑚 |
| 5 分钟路演 | 大字海报式 + 珊瑚满版章节页 |
| 技术评审 / 内部 | 技术蓝图风 + 珊瑚关键路径色 |
| 需要与产品视觉统一 | 珊瑚 + 产品青双色桥接 |

**最终倾向**：主方案用珊瑚单强调；Verify/Explain 局部切档案纸质感；封面和结尾用满版珊瑚。避免 15 页全是同一种白底橙字。

## 15 页映射（定稿）

| 页 | 模板 | 底色 / 强调 | 内容 |
|---|---|---|---|
| 1 封面 | cover | 珊瑚满版，白色衬线 88pt | Voyage · 可信的 AI 旅行决策系统 |
| 2 痛点 | content（三卡） | 纸底 + 珊瑚关键词 | 不可验证 / 不可重规划 / 不可解释 |
| 3 闭环 | content | 纸底 + 珊瑚路径图 | Plan→Verify→Replan→Explain |
| 4 Plan | content | 纸底，右侧截图 | 对话规划 |
| 5 Verify | archive | 象牙 `#F5F1E8` | 校验面板 + 状态胶囊 |
| 6 Replan | archive | 象牙 | “安排过密 → 一键修复” |
| 7 Explain | archive | 象牙 | 来源、置信度、注册角标 |
| 8 产品全流程 | content（双图） | 纸底 | 工作区 + Today |
| 9 移动端 | content | 纸底 | 手机竖屏 |
| 10 3D 场景 | content | 纸底 + 深色图框 | 洪崖洞 GLB 场景 |
| 11 三入口 | content（矢量） | 纸底 | Web / CLI / MCP |
| 12 诚实降级 | split | 纸底 + 双色分屏 | 真实 vs 估算 / 四级 Provider |
| 13 工程数字 | data | 象牙 + 96pt 衬线数字 | 测试、E2E、性能 |
| 14 安全开源 | content | 纸底 | MIT、本地优先、凭据边界 |
| 15 结尾 | cover | 珊瑚满版 | 使命一句话 + 仓库二维码 |

章节过渡不单独占页：用「纸底 + 6×24px 珊瑚竖条 + 页码」表达，全片满版页不超过 4 页。
