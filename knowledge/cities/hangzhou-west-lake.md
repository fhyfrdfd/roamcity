# 环湖节奏

西湖环湖距离长，节假日和周末人流密集。应按片段安排而不是整圈步行，并在片段之间预留交通或休息；不要把多个湖边景点与博物馆硬塞在同一天。

# 天气与体力

降雨或高温时应优先室内替代或缩短户外段，骑行与步行不要安排得过密。老人、儿童和低步行耐受用户应减少环湖距离，选择短段游览。

# 事实边界

游船、景区交通、开放时间和临时管控以官方渠道或实时 provider 为准。
